# Esoft Backend

NestJS API for Esoft.

Use project commands from the repository root:

```bash
npm install
npm run dev
npm run build
npm run lint
npm run test
npm run test:e2e
npm run start
```

Backend workspace scripts are kept for root orchestration and focused
maintenance tasks.

Useful backend workspace commands:

```bash
npm run prisma:generate --workspace backend
npm run prisma:migrate --workspace backend
npm run prisma:studio --workspace backend
```
