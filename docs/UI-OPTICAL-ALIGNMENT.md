# Оптические отступы

Значения задаются только в `frontend/src/shared/ui/tokens.css`.

| Контекст                                                                          | Токен                   | Значение |
| --------------------------------------------------------------------------------- | ----------------------- | -------- |
| Заголовки модалок, подтверждений и PDF-просмотра                                  | `--optical-inset-modal` | 4 px     |
| Видимые подписи полей внутри модалок                                              | `--optical-inset-modal` | 4 px     |
| Подписи групп полей в модалках (`fieldset > legend`), включая «Модули» и «Статус» | `--optical-inset-modal` | 4 px     |
| Заголовки страниц                                                                 | `--optical-inset-page`  | 8 px     |
| Компактные заголовки вложенных секций в справочниках                              | `--optical-inset-modal` | 4 px     |

Отступ применяется к тексту через `padding-inline-start`. Контролы, рамки,
таблицы и кнопки вслед за текстом не сдвигаются. Скрытые accessible labels
не получают отступа. Подписи полей используют общий класс `form-field-label`.

Для модалок принят отступ 4 px: половина стандартного радиуса контрола
`--radius-control: 8px`. Это оптическая поправка, а не выравнивание подписи
с текстом внутри поля: внутренний отступ контрола остаётся 12 px.
Радиус самой модалки не определяет отступ её заголовка.

В справочниках главный `h1` использует `--optical-inset-page` (8 px).
Вложенные заголовки «Объекты», «Местонахождения», «Производители» и «Модели»
используют компактный отступ `--optical-inset-modal` (4 px), чтобы сохранять
визуальную иерархию страницы и локальных секций.

Не добавлять локальные значения и не суммировать отступы текста и контейнера.
Изменение дизайн-кода выполняется через токены и общие стили; новый контекст
сначала добавляется в эту таблицу.
