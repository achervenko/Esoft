# Остатки склада

## Административные действия с резервами

В распределении по местам администратор может снять резерв, заимствовать товар на другие нужды или восстановить резерв из свободного остатка. Комментарий обязателен для всех операций. При снятии резерва необходимо приложить документ; при заимствовании и восстановлении вложение необязательно. Снятие меняет потребность проекта, заимствование уменьшает физический остаток и сохраняет потребность, восстановление только закрепляет свободный товар вместо заимствованного.

Заимствование показывается отдельно от физической нехватки. Перемещение использует обеспеченную часть резерва; при нехватке физического обеспечения консолидация недоступна. Фильтр по умолчанию сохраняет видимость товаров с резервом даже при нулевом физическом остатке.

Пока не хватает связи заказа 1С и ручной строки прихода с проектом ESoft: выбор «восстановить / дополнительно зарезервировать» в приходе отложен до появления назначения проекта. Подробный контракт: [резервы backend](../../../../backend/src/warehouse/reservations/README.md).
