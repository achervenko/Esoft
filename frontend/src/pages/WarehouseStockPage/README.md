# Остатки склада

Экран получает агрегированный список товара по складам через stock-overview.
Поиск, фильтры и оконный рендер поддерживают большие списки. Распределение
открывается в StockDistributionModal: товар, общий физический остаток и
количество по каждому месту.

Один AdminModal используется для просмотра, перемещения, консолидации и
корректировки. Перемещение доступно с warehouse.transfers.manage;
административная корректировка — с warehouse.adjustments.manage.

Формы перемещения и консолидации сохраняют исходную команду в sessionStorage
перед отправкой. При неопределённом результате параметры и закрытие блокируются;
повтор использует исходный requestKey. Корректировка сохраняет также исходные
expectedQuantity, actualQuantity и ID вложений. Документ и причина обязательны.
Успех обновляет распределение и родительский список.

API и транзакционные гарантии: [Stock](../../../../backend/src/warehouse/stock/README.md),
[Transfers](../../../../backend/src/warehouse/transfers/README.md),
[Adjustments](../../../../backend/src/warehouse/adjustments/README.md).
