# Складские компоненты представления

Общие компоненты отображают переданные данные. Они не загружают остатки, не проверяют права и не выполняют складские операции.

- `WarehouseItemIdentity` показывает жирное название и ниже обычный приглушённый артикул без подписи. Используется в общей карточке товара, корректировке, мобильных карточках остатков, размещении приходов и строках резервов. При отсутствии артикула строка не выводится.
- `WarehouseItemPhoto` использует существующий `AsyncImage` и заглушку без фотографии. Получает название и URL фотографии товара.
- `WarehouseProductSummary` отображает фото, название, артикул и одно количество с единицей измерения. `quantityLabel` определяет смысл количества: физический остаток, резерв или другой показатель вызывающего компонента. Отображаемые величины не суммируются и не пересчитываются.
- `WarehouseLocationSummary` показывает иконку, название места и количество с единицей. Длинное название сокращается стилями; исходный текст остаётся в DOM и `title`. Компонент не содержит редактирования и других действий.

Компоненты подключают собственные стили, включая адаптивность карточки товара при ширине до 760 px. Селекторы `stock-photo`, `stock-transfer-product`, `stock-transfer-total` и `stock-adjust-location` сохраняют оформление существующих складских страниц. Количества форматируются общей функцией `shared/lib/warehouse-quantity`, без преобразования Decimal в JavaScript number.

Общие интерактивные элементы находятся в `shared/ui`: `AdminModal`, `AppTable`/`DataTable`, `SearchToolbar`, `SearchSelect`, `SelectField`, `FormField`, `TextField`, `Notice`, `useConfirmation`. Специальных копий этих элементов складские компоненты не создают.

Состояния операций, загрузка данных и права остаются у вызывающих страниц и хуков. `StockDistributionModal` сохраняет один экземпляр `AdminModal` при переключении просмотра, перемещения и корректировки. Состав строк распределения и доступность действий определяет `StockDistributionTable`.

`ReceiptItemPicker` выполняет серверный поиск активной номенклатуры через общий `SearchSelect`; используется в ручном приходе, сопоставлении номенклатуры и создании резерва. `useStorageChoices` загружает склады и места постранично, отменяет устаревшие запросы и поддерживает отбор активных мест.
