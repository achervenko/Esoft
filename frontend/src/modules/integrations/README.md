# Интерфейс интеграций

«Пользователи → Интеграции» доступна с разрешением `integrations.manage`. Вкладка сохраняется в адресе `#/users?tab=integration`. Панель показывает подключения к 1С, сопоставления складов и последние обмены.

## Подключения к 1С

Таблица показывает источник, назначение и статус каждого активного подключения. Строки выключенных источников приглушены. Пояснения и коды ошибок открываются через ⓘ. При включённом расписании приходов статус берётся из результата планировщика.

«Добавить» открывает форму источника, карандаш — его настройки. Поддерживаются логин и пароль или готовый заголовок `Authorization`. При редактировании пустые поля доступа сохраняют текущие данные. В настройках можно выбрать направления обмена и задать расписание приходов. Сервер сохраняет источник и потоки одним запросом через `/api/integrations/sources`.

## Сопоставление складов

Цепочка открывает таблицу складов для источника с потоком приходов. В неё входят склады из полученных накладных, собственные связи источника и общие UUID-связи для складов, которые этот источник передавал. UUID приводятся к каноническому виду на сервере. Старые идентификаторы сохраняют регистр.

Склад ESoft выбирается в строке. Сопоставленные строки выделены зелёным. «Сохранить» появляется после изменения выбора. Список формируется из сохранённых накладных и связей. Несопоставленные склады пропускаются при импорте, а сохранение связи не запускает обработку старых накладных.

## Последние обмены

Журнал читает существующую историю запусков заказов и приходов через `GET /api/integrations/runs`. По умолчанию выбран текущий день по Москве. Можно выбрать период, источник, назначение и результат. Новые запуски идут сверху. В строках видны время, результат, количество полученных документов и подробности ошибки через ⓘ.

Таблица использует `DataTable.windowed`, а порции загружаются через `useIncrementalList` и `ListLoadMore`. «Обновить» перечитывает журнал. Карточки входящих API-ключей и очереди событий сняты с вкладки. Их серверные API сохранены.
